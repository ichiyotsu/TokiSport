# TokiSport

Toki 系列体育应用（Android）。「竞技」页按联赛统一展示比赛成绩，「积分」页展示各球队积分、比分与阵容。

- 版本：0.1.2（versionCode 3）
- 包名：`com.tokisport.app`
- 设计：**TokiMusicUI 设计规范**（MD3E 框架）：固定结构色板（页底深色纯黑 / 浅色纯白，卡片 #1C1C1E / #F2F2F4；主色为本应用种子紫 #6750A4）、玻璃 chrome（标题头与悬浮底栏走加强档：Haze 32dp 模糊 + 45% veil，采样不可用时以 Haze fallback 上色兜底）、统一标题头（玻璃标题 chip + 56dp 玻璃返回 chip，顶栏右侧头像进「我的」）、悬浮底栏（纯图标、64×56dp 条目、选中为中性灰紫 pill #54545F / #D9D6E2）、分组列表（分段圆角 28/4dp）、圆角阶梯 4/8/12/16/28、24dp 页边距
- 字体：全局内嵌 **Inter**（可变字体，中文回退 Noto Sans SC）；**队伍分数使用 Google Sans Flex**（比分、积分、胜平负、进失球、焦点数据等数字统一走 `ScoreText`）。字体文件位于 `app/src/main/res/font/`（inter.ttf / noto_sans_sc.ttf / google_sans_flex.ttf），Google Sans Flex 与 Noto Sans SC 的许可见 `app/src/main/assets/licenses/`
- 队徽：各国家队使用**真实队徽**（来源 TheSportsDB 国家队徽标，内嵌于 `app/src/main/res/drawable-nodpi/crest_*.png`，离线可用；U17 球队用其足协成年国家队队徽）。覆盖全部 52 支有战绩记录的球队及 9 支仅出现在比分里的球队；查不到真实队徽时才回退彩色首字圆 / 国旗，绝不绘制或伪造队徽

## 功能

- **竞技页**：顶部头条只保留焦点比赛（赛事 · 阶段 · 时间 + 紧凑比分行）、标题与一句话介绍，点按进入焦点二级页（焦点数据、焦点比赛、赛程在那边）；以下不分区，全部赛事的比赛成绩统一展示、按联赛（赛事）分栏、赛事内按阶段分组
- **积分页**：横向赛事筛选芯片 + Sofascore 式积分表（小组赛按组出表；名次左侧色条标示出线区，冠军行高亮；紧凑数字列 赛/胜/平/负/进:失/净/分，数字用 Google Sans Flex，积分列最强），点球队进入球队页
- **球队页**（介绍主导）：大队徽 + 简介（由快照字段拼成）、近五场胜/平/负状态（点按进对应比赛）、所在联赛积分表、全部比赛、战绩数据、阵容
- **比赛详情页**（全局可达，点任何一场比赛行进入）：大比分与所在联赛/阶段/时间、进球与比赛记录（快照 note 原文）、首发阵容（仅收录到的场次：世界杯决赛两队、中国 U17 三场）、对抗数据（快照内历史交锋 + 两队本届数据对比）。快照没有的数据（控球、射门、评分等）不编造，缺失处如实标注暂无数据
- **「我的」页**（顶栏头像进入，结构同 TokiMusic「我的」）：头像卡 + 数据源开关分组（见下）+ 关于分组；原设置页功能已全部并入，底栏只剩竞技 / 积分两页

页面布局参考 Sofascore：共享比赛行（左固定宽状态列「日期 · 完场」+ 两行球队（真实队徽）+ 右侧两行比分对齐成列；获胜方队名与比分加粗、落败方弱化，平局两边同等，胜负由真实比分推导）、比赛按赛事阶段分组成容器（组头行 + 细分隔线）。

## 数据与来源

三个预备数据源：**Google Sports、直播吧、懂球帝**。「我的」页有三个开关（默认全开）：

- 页面展示的是**已启用数据源的综合结果**：同一条记录只显示一次，并标注来源（如「Google Sports · 直播吧」）。
- 只被已关闭数据源核实的记录会从综合结果中隐藏；阵容同理。
- 三个来源应当一致；将来实时同步若发现冲突，按**多数决（3 中取 2）**采信并标记冲突（0.1.0 快照无冲突）。

0.1.0 为**本地快照**（2026-11-27 核对），数据层按 Google Sports 的 games / standings / teams 结构建模，快照记录逐条标注来源：

- 比分/积分：Google Sports 结果，经 FIFA 赛事报道交叉核对
- 阵容：直播吧首发名单（2026 世界杯决赛西班牙/阿根廷、中国 U17 三场小组赛逐场首发）
- 懂球帝：仅标注在其比赛页实际核对过的记录（U17 中国队小组赛）

说明：Google Sports **没有官方免费 API**。后续接入实时数据时，可通过 SerpApi / SearchApi 等解析服务新增一个实现同一 `SportsDataSource` 接口的数据源（需自备 API Key），UI 无需改动。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 37 / targetSdk 36 / minSdk 36）：

```bash
gradle :app:assembleDebug
```

本仓库在本机（与 TokiCast 共用工具链）可用 `~/workspace/tools/build-tokisport.sh :app:assembleDebug` 构建。

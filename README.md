# TokiSport

Toki 系列体育应用（Android）。主页展示赛事概览，「战绩」页展示各球队比分、积分与阵容。

- 版本：0.1.0（versionCode 1）
- 包名：`com.tokisport.app`
- 设计：MD3E + TokiUI 0.2.0-b1（种子色 #6750A4、HCT 动态取色、语义圆角阶梯 4/8/12/16/28、24dp 页边距、悬浮胶囊底栏：主页 / 战绩 / 设置；底栏不采样窗口内容，按 TokiUI 实色回退：不透明表面 + 3dp 强调色描边）
- 字体：全局内嵌 **Inter**（可变字体，中文回退 Noto Sans SC，与 TokiUI 搭配一致）；**队伍分数使用 Google Sans Flex**（比分、积分、胜平负、进失球、焦点数据等数字统一走 `ScoreText`）。字体文件位于 `app/src/main/res/font/`（inter.ttf / noto_sans_sc.ttf / google_sans_flex.ttf），Google Sans Flex 与 Noto Sans SC 的许可见 `app/src/main/assets/licenses/`

## 功能

- **主页概览**：赛事切换（2026 FIFA 世界杯 / 男足 U17 世界杯）、焦点卡、焦点比赛卡（大号比分）、焦点数据、按阶段分组的比赛列表、紧凑战绩预览、即将进行
- **战绩页**：横向赛事筛选芯片 + Sofascore 式积分表（小组赛按组出表；名次左侧色条标示出线区，冠军行高亮；紧凑数字列 赛/胜/平/负/进:失/净/分，数字用 Google Sans Flex，积分列最强），点球队进入详情（比赛 / 数据 / 阵容三个标签页）

页面布局参考 Sofascore 重构：共享比赛行（左固定宽状态列「日期 · 完场」+ 两行球队 + 右侧两行比分对齐成列；获胜方队名与比分加粗、落败方弱化，平局两边同等，胜负由真实比分推导）、比赛按赛事阶段分组成容器（组头行 + 细分隔线）、球队详情页头 + 标签页结构。国旗 + 彩色首字圆仍为 logo 占位，不使用伪造队徽。
- **设置页**：数据源开关（见下）与关于信息

## 数据与来源

三个预备数据源：**Google Sports、直播吧、懂球帝**。设置页有三个开关（默认全开）：

- 页面展示的是**已启用数据源的综合结果**：同一条记录只显示一次，并标注来源（如「Google Sports · 直播吧」）。
- 只被已关闭数据源核实的记录会从综合结果中隐藏；阵容同理。
- 三个来源应当一致；将来实时同步若发现冲突，按**多数决（3 中取 2）**采信并标记冲突（0.1.0 快照无冲突）。

0.1.0 为**本地快照**（2026-11-27 核对），数据层按 Google Sports 的 games / standings / teams 结构建模，快照记录逐条标注来源：

- 比分/积分：Google Sports 结果，经 FIFA 赛事报道交叉核对
- 阵容：直播吧首发名单（2026 世界杯决赛西班牙/阿根廷、中国 U17 三场小组赛逐场首发）
- 懂球帝：仅标注在其比赛页实际核对过的记录（U17 中国队小组赛）

说明：Google Sports **没有官方免费 API**。后续接入实时数据时，可通过 SerpApi / SearchApi 等解析服务新增一个实现同一 `SportsDataSource` 接口的数据源（需自备 API Key），UI 无需改动。

## 构建

需要 JDK 17 与 Android SDK（compileSdk 37 / targetSdk 36 / minSdk 36）：

```bash
gradle :app:assembleDebug
```

本仓库在本机（与 TokiCast 共用工具链）可用 `~/workspace/tools/build-tokisport.sh :app:assembleDebug` 构建。
